# AI Exam Preparation Planner

## Project Overview
The AI Exam Preparation Planner is a web-based application designed to help students organize their exam preparation and manage their study activities efficiently.

## Objectives
- Organize exam preparation activities.
- Help students plan their study schedules.
- Track study tasks and progress.
- Provide a simple and user-friendly interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Files
- `index.html` – Main webpage structure.
- `style.css` – Styling and layout.
- `script.js` – Application functionality.

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
